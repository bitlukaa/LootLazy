# Security Policy

## Supported versions

Security fixes are provided for the latest stable release. Update to the current version before reporting a problem.

## Report a vulnerability

Use GitHub's private vulnerability reporting option in the repository's **Security** tab when available.

If that option is unavailable, open an issue titled **Security contact request** without including exploit details. A maintainer can arrange a private reporting channel.

Please include the affected version, a clear description, reproduction steps, and the likely impact. Do not publish exploit instructions before maintainers have had a chance to investigate.

Never send passwords, account tokens, or unredacted private diagnostics.

## Account safety

LootLazy does not request Discord account credentials or automatically accept quests or claim rewards. This policy does not guarantee that platform use will be free from account restrictions or bans.

## Third-party components

LootLazy includes third-party components with their own licenses. Their notices are preserved in distributed packages.
