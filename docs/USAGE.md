# Setup and usage

## Windows setup

LootLazy supports Windows 10/11, 64-bit. Microsoft Edge WebView2 is required; Setup can download it if needed.

- Installer: run the Setup executable from the latest GitHub release.
- Portable: extract the ZIP and open LootLazy.exe. Keep the folder's data when updating.

## Discord and Steam

Keep Discord Desktop open for Discord activity and quests. Accept quests in Discord, select Desktop, and claim rewards in Discord yourself.

Steam sessions require your signed-in Steam desktop client, ownership of the selected game, and a compatible Valve-signed runtime from an installed Steam game. The selected title itself does not need to be installed. Steam determines trading-card eligibility and drop timing; LootLazy does not track remaining card drops.

Manual sessions let you enter an executable name yourself. Discord activity depends on Discord recognizing the process.

## Updates

Use Check updates in Settings. Stop active sessions before installing an update.

Versions earlier than 3.6.11 may need a one-time manual upgrade to the latest release because older update helpers use a different executable name or signing protocol. Preserve the portable data folder.

## Privacy and platform rules

LootLazy does not request Discord passwords or account tokens. It does not automatically accept quests, claim rewards, or read your account's quest progress. Local session helpers do not inject code into games or modify game files or memory.

Local timers do not guarantee badge progress, recorded Steam hours, card drops, or quest rewards. Follow each platform's rules; account restrictions cannot be ruled out.
