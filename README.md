# Questro

A small game-session helper for Discord's desktop-play quests.

Downloading a huge game just for a short quest is a bit much. Questro runs a lightweight local game process instead, so Discord can recognize game activity without a full game installation. Pick a game, choose how long to run it, and start your session.

## What you can do

- Find a game and start it with its available executable name already selected.
- Keep the game list up to date automatically.
- Run a timed session, or leave it running until you stop it.
- Pick a few games and let your queue run them in order.
- Start a session straight from a desktop-play quest card.
- Choose light or dark mode, and English or Arabic.
- Check for new releases and read what's new in Settings.

## Discord stays manual

Questro doesn't ask for your Discord login or token, scrape your account, or inject scripts into the client. You accept the quest, select Desktop, check your progress, and claim the reward in Discord yourself. Questro handles the local game sessions you choose.

It's an unofficial helper. Some games or quests may need the real game, and detection, rewards, and account safety aren't guaranteed.

## Get Questro

Download the portable ZIP from [Releases](https://github.com/bitlukaa/Questro/releases), extract it, and open **Questro.exe**.

Windows 10 or 11, 64-bit. If WebView2 is missing, get the [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

Have a game that won't show up, or something that feels off? [Open an issue](https://github.com/bitlukaa/Questro/issues) and tell us what happened.
