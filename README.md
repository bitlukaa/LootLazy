# Questro

A lightweight Windows desktop app for managing game sessions and desktop-play quests.

## Features

- Search games and choose their available Windows executable.
- Set a session duration or keep it running continuously.
- Schedule games to run one after another with individual durations.
- Browse desktop-play quests and start sessions directly from their cards.
- Stop, cancel, or reopen your local quest sessions.
- Switch between English and Arabic, and light and dark themes.

## Download

Download the Windows portable ZIP from [Releases](https://github.com/bitlukaa/Questro/releases).

Extract the ZIP, then open **Questro.exe**. No installation is needed.

Questro supports Windows 10 and 11, 64-bit. If Windows asks for WebView2, install the [Microsoft WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Getting started

1. Open Discord's desktop app.
2. In Questro, select a game and choose its session duration.
3. Click **Start simulation**. To schedule another game, select it and click **Play next**.
4. Open **Queue** to edit or reorder upcoming games.

For quests, accept the quest in Discord first, then use **Start Quest** in Questro. The countdown shows your local session time; check progress and claim rewards in Discord.

## Your settings

Your preferences and history stay with the app. Keep the extracted folder together when moving it or updating it.
